1. **First Run**: Start with public test server, not important server
2. **Token Safety**: Never commit `appsettings.Development.json` to GitHub
3. **Testing**: Use F12 browser DevTools to test at 400x300px
4. **Permissions**: Ensure bot has "Read Message History" permission
5. **Debugging**: Check Debug output (Ctrl+Alt+O) if things don't work
